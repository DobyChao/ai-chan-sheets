# DeepSeek娘（鲸鱼娘）· 暖风旅装 v01

本目录为用户指定的换装衍生方案，包含文字设定、参考图、22条制作提示词与4版正面预览。当前推荐为v04闭嘴微笑版；其余三视图、表情和细节素材尚未生成，未制作完整设定板。原项目完整保留。

## 设计定位

同一位鲸鱼娘换上适合秋日旅行的针织与皮革便装。蓝色头发与鲸鱼身体特征维持原身份，奶油白毛衣让上身明亮柔软，砖红围巾形成主视觉，棕色皮具和哑光黄铜收束装备细节。整体是温暖、轻装、略有复古旅行感，不额外扩展齿轮或机械装备。

可选二创叙事：她喜欢在沿海小镇慢慢旅行，习惯先观察再思考，用温和、好奇的态度面对新事物。该性格与旅行主题为本次创作建议，不是仓库证实的原作者设定；不改变角色品牌身份。

## 固定服装设定

| 部位 | 本版约定 |
|---|---|
| 头部 | 黄铜框护目镜置于头顶；鲸鱼发夹与红结在角色右鬓，避让原鳍耳 |
| 上衣 | 奶油白高领、双肩镂空、绞花针织、宽松长袖、罗纹袖口，下摆扎入裤腰 |
| 颈部 | 砖红窄长围巾，双尾垂至小腿附近，末端轻微磨损 |
| 下装 | 深藏青高腰短裤、前中铜扣、浅灰蓝翻边；棕色腰带与双皮背带 |
| 后腰 | 双背带不交叉；有包边尾根开口，腰带避让尾柄（推定补全） |
| 腿部 | 深蓝灰罗纹过膝袜，留少量大腿露肤；右大腿单圈棕色扣带 |
| 鞋 | 棕色翻筒系带低跟短靴，金属侧扣和少量红色系带 |
| 配件 | 左胸鲸鱼黄铜胸针、左髋翻盖腰包、右前腰黄铜吊饰与红流苏 |

左右均指角色自身。正面：发夹和腿带在画面左，腰包在画面右。背面自然反投影，不能单独镜像某个附件。用户参考的遮挡和视图间位置歧义以此表为本版统一约定。

参考色（从图像视觉估算，并非仪器取样）：深蓝 #39465E、浅蓝 #80A4C7、奶油白 #F2E6D2、砖红 #B95343、黄铜 #AC8750，皮革另用深棕 #634A38。材质分别为哑光毛线、厚实布料、轻度旧化皮革与低反光金属。

## 可直接使用的正面完整提示词

传入两张参考：图A为仓库原角色立绘，图B为本目录服饰参考。下面全文可以直接粘贴，也已写入“提示词/A01_三视图_正面.json”。
【身份与参考分工】
图A（仓库原图_立绘_鲸鱼女仆.png）只负责角色身份、脸型、身体比例、发色、瞳色与鲸鱼身体特征；图B（用户服饰参考.png）只负责新服装、装备的造型、材质和配色。保持图A的同一位DeepSeek娘，不照搬图B的脸型或头顶叶芽。沿用图A精细日系二次元画风、清晰线稿、柔和薄涂与赛璐璐色块。
保留深蓝厚重长发、浅蓝发梢渐变与挑染、蓝色双眼、柔和脸型与淡粉腮红，保留一根细长弯曲、向上卷成环的呆毛。耳位保留一对深蓝鲸鱼鳍耳，浅蓝高光、白色羽状鳍条与蓝色小蝴蝶结，不能换成猫耳、兔耳或普通人耳。腰后保留深蓝鲸鱼尾，尾端为两片水平展开的尾叶，不是竖直鱼尾；尾巴不是围巾、头发或挂件。全身视图必须交代尾鳍，近景仅呈现自然进入取景范围的身体部位。
【新服装】
以图B为服装依据：奶油白高领露肩绞花针织毛衣，领筒包住颈部，肩部独立镂空，蓬松长袖在上臂处起始，罗纹袖口，前胸清晰纵向绞花，下摆收进短裤。砖红色长围巾松绕颈部，前方横覆领口，长尾自然垂至小腿附近，末端有轻微不规则磨损；它是窄长围巾，不画成整片披风。深藏青高腰短裤，前中铜色排扣、翻折浅灰蓝裤脚、棕色宽腰带与黄铜方扣。两条棕色皮背带由前腰跨过肩头通向后腰，不增加背包。深蓝灰色罗纹过膝长袜，袜口与裤脚间有一小段大腿露肤；棕色低跟系带短靴，翻折靴筒、金属侧扣与少量砖红系带。
黄铜框双目护目镜固定在头顶棕色皮带上，不遮眼、不挤压鳍耳。角色右鬓增加一枚蓝白小鲸鱼发夹和砖红蝴蝶结，位于鳍耳前上方，不能替代鳍耳；左胸一枚小型黄铜鲸鱼胸针；角色左髋一个棕色翻盖腰包；角色右前腰一枚黄铜小吊饰配砖红流苏；角色右大腿一圈棕色扣带，位于袜口上方，不增加武器。左右一律指角色自身：正面图的右鬓发夹与右腿扣带位于画面左侧，左髋腰包位于画面右侧；背面图左右投影随视角自然转换。
配色为深蓝、浅蓝、奶油白、砖红、棕色皮革及少量哑光黄铜。红色限于围巾、发饰与少量系带流苏，头发和眼睛不变红。毛衣柔软哑光，短裤厚实，皮具有轻微使用痕迹，金属低反光。完全替换女仆头饰、蕾丝垂带、围裙、女仆马甲与多层长裙、黑蝴蝶结宝石颈饰、白色连裤袜和玛丽珍鞋，不把旧装叠穿进新装。
【补全规则】
背面皮背带采用不交叉双直带连接后腰；短裤后腰为尾柄设置有包边的开口，使尾巴从腰后自然伸出，腰带绕开尾根。此两项是本次换装的推定补全。围巾两尾从后肩垂下并适度分开，与头发、背带、尾鳍相互区分。长发自然分束，允许局部遮挡，但不能为了展示结构任意剪短头发。
【共用绘制约束】
纯白无纹理背景、均匀柔光，无纸张纹理、场景、色卡、标题、文字、标尺、水印或Logo。每张只画任务指定的一个视图或一组单品，禁止附加人物、小插图、拼贴和网格。正交设定视角，比例稳定，不用广角或戏剧透视。不要照片、3D塑料质感、夸张胸腰比例、手部畸形或额外肢体。只呈现当前取景范围应出现的内容，单品特写不画人物或其它服装，表情胸像不强塞尾巴、短裤和鞋。
【本张专属任务】
只画严格正面全身立绘，头脸和躯干正对观众。竖直站立，双脚平行，双臂略离身体，手指自然放松，空手，闭嘴自然微笑，嘴角轻扬，保留温柔眉眼，不露齿。环状呆毛到靴底完整入画，上下留白，人物约占画面高度90%。清楚展示两侧鳍耳、毛衣肩部开口、双前背带、短裤排扣和翻边、腰包、右腿扣带与袜口；尾鳍从身体轮廓一侧自然露出，不遮挡主要服装。不要三分之四角度或参考图的多人物排版。

## 目检重点

1. 同一张脸、蓝眼和发梢渐变；环状呆毛没有被叶芽替换。
2. 双侧鳍耳、蓝结与白鳍条保留；鲸鱼发夹没有取代鳍耳。
3. 尾巴是水平分叉鲸尾；尾根开口合理，与围巾和头发分离。
4. 右鬓发夹、右腿扣带、左髋腰包位置在各视图一致。
5. 高领与露肩同时成立；围巾是长条，未变成披风。
6. 背带能连接前后裤腰；纯侧面没有变成三分之四侧。
7. 无旧围裙、旧裙装、玛丽珍鞋、白连裤袜、纸纹、色卡和多余文字。
8. 背视中被头发遮住的结构不得声称已由原图证实。
